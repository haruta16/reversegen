## 1. 全局指标

| 指标 | 值 | 解读 |
|------|-----|------|
| 在线胜率均值 | **42.58%** (σ=23.06) | 整体偏难 |
| 模拟胜率均值 | **82.22%** (σ=23.43) | 模拟明显偏高 |
| **Pearson r** | **0.5305** | 中等正相关 |
| **Spearman ρ** | **0.5573** | 中等正相关（排序能力略好） |
| **R²** | **0.2815** | 仅 28.1% 方差可解释 |
| MAE | 39.96% | 平均绝对误差 |
| RMSE | 45.59% | 均方根误差 |
| 系统性偏差 | **+39.64%** | 模拟系统性高估 |

### 线性回归模型

```
simWR = 0.5389 × onlineWR + 59.27
```

- **斜率 0.54**：在线胜率每变化 10%，模拟只响应 ~5.4%，说明模拟器对难度变化的**敏感度不足**
- **截距 59.27%**：即使在线胜率趋近于 0%，模拟器也预测约 59% 的胜率 — 模拟器几乎总能找到可行策略

## 3. 按在线难度分层

| 层级 | 数量 | 在线均值 | 模拟均值 | 偏差 | MAE | r |
|------|------|---------|---------|------|------|-----|
| 极难 (0-30%) | 922 | 17.0% | 66.6% | **+49.6%** | 49.9% | 0.207 |
| 困难 (30-50%) | 766 | 40.0% | 83.7% | +43.7% | 44.3% | 0.210 |
| 中等 (50-70%) | 654 | 59.1% | 92.9% | +33.7% | 33.9% | 0.196 |
| 较易 (70-85%) | 314 | 76.6% | 97.6% | +21.0% | 21.1% | 0.202 |
| 极易 (85-100%) | 86 | 89.7% | 99.5% | +9.8% | 9.8% | 0.294 |

### 分层发现

1. **偏差随难度递减**：极难关 +49.6% → 极易关 +9.8%。模拟器在简单关卡更接近真实
2. **层内相关性极低**：每层内的 Pearson r 仅 ~0.2，说明在同一难度带内，模拟器几乎无法区分更难和更易的关卡
3. **极难层分布最广**：922 个关卡（33.6%），且模拟均值 66.6% — 这些关卡对模拟器来说是「中等偏易」，但对人类是「极难」

## 6. 核心结论

### 6.1 模拟器的定位

当前玩家模拟求解器是真实玩家水平的**上界估计（upper bound）**：

- 它能证明「这个关卡理论上可以赢」（如果 sim < 100%，则存在结构死局）
- 它不能直接预测「玩家实际会不会赢」
- 差值 `simWR - onlineWR` 可以理解为**「人类偏差指数」** — 越大说明越反直觉

### 6.2 为什么模拟器严重高估

| 能力 | 模拟器 | 真实玩家 |
|------|--------|---------|
| 可见匹配组枚举 | 穷举所有 C(n,3) 组合 | 只能注意到 2-5 个明显组合 |
| 依赖路径分析 | 精确计算 cost | 凭直觉估计 |
| 无安全组时的决策 | 精确计算 unlockGain，选最优 | 随机点或凭直觉 |
| 时间压力 | 无 | 有（部分关卡限时） |
| 操作失误 | 无 | 有（点错、看错花色） |
| 疲劳/注意力衰减 | 无 | 有 |
| 策略一致性 | 始终执行同一策略 | 策略摇摆、试错 |

### 6.3 最有价值的应用场景

1. **难度上界校验**：如果 simWR < 50%，则该关卡**必然极难**，需调整
2. **人类偏差指数**：`onlineWR / simWR` 越低 → 关卡越「反直觉」，需检查布局是否具迷惑性
3. **关卡排名**：Spearman ρ=0.56 说明排序有一定参考价值，但不能精确预测数值
4. **极端检测**：online=0% & sim=100% 的关卡值得人工复查 — 可能是布局设计问题
